# ADR-0002 · 路由级 i18n，而不是样例的双 DOM 方案

**状态**：已采纳 · 2026-09-16

## 背景

参考样例用「双 DOM」实现双语：中英两段文字同时存在于 HTML 里，用 `hidden` 属性切换。

## 决策

改用路由级 i18n：`/zh/...` 与 `/en/...` 是两个独立的静态页，语言切换是纯 `<a>` 跳转。

## 理由

| | 双 DOM | 路由级 |
|---|---|---|
| DOM 体积 | 翻倍 | 不变 |
| 搜索引擎 | 两种语言混在一个页面里 | 分别索引，可用 hreflang 互指 |
| 语言切换 | 需要 JS | 纯链接，零 JS，右键新标签正常工作 |
| 演示内部文案 | **无解**（脚本里的字符串没法双 DOM） | 作为 prop 传入，同样双语 |
| 一致性校验 | 无法机器检查 | 可比对结构 |

最后一行是决定性的：样例的方案里，演示组件内部的滑块标签、图例、坐标轴标题**根本没有办法双语**。

## 代价

- 页面数翻倍（21 页而非 11 页）。对静态站点这不是问题。
- 切换语言时需要保留当前 hash（小节 + 面板）。本站在 `TopBar.astro` 用 6 行客户端脚本补上了这一点。
